# MyanMart

A Myanmar-first multi-vendor online marketplace connecting sellers and buyers.

## Features
- Buyer and seller accounts
- Seller storefronts and product listings
- Product search and categories
- Shopping cart and checkout
- Multi-seller orders
- Manual Myanmar payment verification
- Seller fulfillment management
- Admin moderation

## Requirements
- Node.js LTS
- PostgreSQL
- npm
- S3-compatible object storage for production uploads

## Getting Started
1. Install dependencies.
2. Configure environment variables.
3. Create the PostgreSQL database.
4. Run Prisma migrations.
5. Start the API and frontend development servers.

See `docs/` for product requirements, architecture, database/API specifications, and implementation phases.

## Project Principle
Build a reliable, simple marketplace for Myanmar first. Prioritize the complete buyer-to-seller purchasing workflow before adding advanced features.
